보험 목록과 보험 등록/편집 진입점을 관리한다. 보험 문서는 각 보험 행의 문서 추가에서 연결한다.

보험 등록/편집 관리 홈
보험 문서는 상단 주요 버튼으로 등록하지 않는다. 먼저 보험을 등록하거나 목록에서 보험을 선택한 뒤 편집 또는 문서 추가 액션으로 연결한다.

등록된 보험 관리 목록

보험 가족 보험사 계약 상태 문서 연결 상태 약관/계약서 검색 상태 편집 문서 추가 삭제 사용 중지
보험 A 가족 A 보험사 A 유지 후보 문서 추가 필요 문서 추가 필요 사용 전 확인 필요 편집 문서 추가 삭제 사용 중지
보험 B 가족 B 보험사 B 유지 후보 연결 후보 있음 약관 1건 / 계약서 1건 일부 후보 확인 필요 편집 문서 추가 삭제 사용 중지
화면 목적
보험 목록을 관리하고 선택한 보험 기준으로 문서 추가 흐름에 진입한다.
입력값
보험 등록/편집, 편집, 문서 추가, 삭제, 사용 중지
저장값
보험 관리 정보
조회값
등록 보험 목록, 문서 연결 상태
민감정보 여부
있음. 보험 계약 정보는 민감정보다.
다음 이동
