# 가족 보험 청구 참고 조회기 기준 지침서

## 1. 문서 목적

이 문서는 `가족 보험 청구 참고 조회기` 프로젝트의 현재 기준 지침서다.

이 프로젝트는 가족의 보험, 약관, 병원 서류, 청구 이력, 지급 결과를 로컬에서 관리하고, 병원비 청구 전 참고할 수 있는 담보 후보를 조회하는 개인용 프로그램을 목표로 한다.

이 문서는 공통 운영 지침의 역할 분리, Markdown 문서화, 확인 사실과 추정 분리, 금지 작업 명시 원칙을 따른다.

---

## 2. 프로젝트 정의

### 프로젝트명

가족 보험 청구 참고 조회기

### 프로젝트 성격

- 개인용 로컬 프로그램
- 가족 보험 관리 도구
- 병원 청구 참고 조회 도구
- 보험금 자동 판정 도구가 아님
- 고객 관리 서비스가 아님
- 외부 API 기반 보험 조회 서비스가 아님

### 한 문장 정의

가족이 가입한 보험, 약관, 병원 서류, 청구 이력, 지급 결과를 로컬에 저장하고, 사용자가 확인한 데이터 기준으로 청구 가능성이 있는 보험 담보 후보를 찾아주는 개인용 로컬 프로그램이다.

## 5. AI / OCR 기준

이 프로젝트에서 사용자가 배제하려는 AI는 `개인정보가 외부로 전송되거나 학습에 사용되는 AI`다.

따라서 다음 기준을 적용한다.

| 구분 | 사용 여부 | 판단 |
|---|---:|---|
| 외부 LLM 분석 | 금지 | 의료·보험 정보 외부 전송 위험 |
| 클라우드 OCR | 금지 | 진단서/영수증 이미지 외부 전송 위험 |
| 로컬 OCR | 허용 | PC 내부에서만 문자 인식 |
| 로컬 이미지 전처리 | 허용 | PC 내부 처리 |
| 규칙 기반 조회 | 허용 | 학습이 아니라 조건 매칭 |
| 과거 청구 이력 검색 | 허용 | 로컬 기록 재조회 |

## 7. 핵심 데이터 흐름

```text
원본 파일 등록
→ OCR 또는 텍스트 추출
→ 후보 데이터 생성
→ 사용자 확인·수정
→ 확정 데이터 저장
→ 보험 담보 규칙 및 과거 청구 이력 조회
→ 청구 참고 결과 표시
```

### 절대 원칙

```text
OCR 결과 ≠ 확정 데이터
사용자 확인 데이터 = 확정 데이터
```

- 입금 확인 필요

### 금지 표현

- 청구 가능 확정
- 보험금 지급 확정
- 보장 불가 확정
- 예상 보험금 확정

## 11. 개발 기술 후보

현재 기준 후보는 다음과 같다.

```text
.NET WPF 또는 WinForms
+ LiteDB 또는 암호화 JSON
+ 로컬 attachments 폴더
+ Tesseract OCR
+ OpenCV 이미지 전처리
+ PdfPig PDF 텍스트 추출
+ Open XML SDK DOCX 텍스트 추출
+ 외부 API 없음
+ 클라우드 저장 없음
```

기술은 Codex 개발 착수 전 별도 `TECH_DECISION` 문서에서 확정한다.
