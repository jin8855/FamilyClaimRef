# 기능명세서: 가족 보험 청구 참고 조회기

## 1. 기능 모듈 목록

| 모듈 | 설명 | MVP |
|---|---|---:|
| 가족 구성원 관리 | 가족 별칭과 관계 관리 | 포함 |
| 보험 목록 관리 | 보험사, 상품명, 피보험자, 계약상태 관리 | 포함 |
| 보험 목록 OCR 등록 | 캡처/PDF에서 보험 후보 추출 | 포함 |
| 약관 문서 관리 | 약관 PDF/DOCX 등록 및 연결 | 포함 |
| 담보/특약 관리 | 약관에서 추출한 담보 후보 확인 저장 | 포함 |
| 병원 서류 OCR | 진단서/영수증/약제비 영수증 OCR | 포함 |
| OCR 결과 확인 | 후보값 확인·수정·확정 | 포함 |
| 청구 사건 관리 | 하나의 병원 진료 건 관리 | 포함 |
| 보험사별 청구 관리 | 한 청구 사건을 여러 보험에 청구 | 포함 |
| 지급 결과 관리 | 실제 지급/부지급/삭감 관리 | 포함 |
| 청구 참고 조회 | 진단코드·진료구분 기준 담보 후보 조회 | 포함 |
| 미청구 체크 | 서류는 있으나 청구 이력 없는 건 표시 | 포함 |
| 입금 확인 체크 | 청구 후 지급 결과 없는 건 표시 | 포함 |
| 백업/복원 | 로컬 암호화 백업 | 2차 |

---

## 2. 가족 구성원 관리

### 입력값

- 표시명
- 관계
- 메모

### 저장 제외

- 주민번호
- 상세 주소
- 민감한 개인 식별번호

### 기능

- 가족 구성원 추가
- 가족 구성원 수정
- 가족 구성원별 보험 현황 조회
- 가족 구성원별 청구 이력 조회

---

## 3. 보험 목록 관리

### 직접 입력 항목

- 보험사
- 상품명
- 피보험자
- 계약상태
- 보험기간
- 증권번호 일부 또는 마스킹 값
- 메모

### 반자동 등록 입력

- 보험 조회 화면 캡처
- 보험증권 PDF
- 보험가입내역 PDF

### 추출 후보

- 보험사명
- 상품명
- 피보험자
- 계약상태
- 보험기간
- 증권번호 일부

### 사용자 확인

OCR 추출값은 자동 저장하지 않고, 사용자가 확인해야 보험 목록으로 승격된다.

---

## 4. 약관 문서 관리

### 지원 파일

- 텍스트형 PDF
- DOCX

### 1차 제외

- 스캔 약관 OCR 자동 분석

### 추출 후보

- 담보명
- 지급사유
- 보상하지 않는 손해
- 한도
- 공제금액
- 면책기간

### 결과 상태

- 후보
- 사용자 확인됨
- 무시됨
- 추가 검토 필요

---

## 5. 담보/특약 관리

### 입력값

- 담보명
- 보험
- 진료구분: 통원/입원/수술/약제비
- 진단코드 규칙
- 비용 구분
- 약관 출처 문서
- 출처 페이지
- 메모

### 진단코드 규칙 유형

- 정확 일치
- prefix 일치
- 수동 메모

### 결과 표시 기준

- 해당 가능 담보
- 확인 필요 담보
- 현재 조건과 불일치

---

## 6. 병원 서류 OCR

### 지원 문서

- 진단서
- 진료확인서
- 진료비 영수증
- 약제비 영수증
- 진료비 세부산정내역서 후보

### 추출 후보

- 환자명
- 진료일
- 병원명
- 진단코드
- 진단명
- 통원/입원 여부
- 입원기간
- 수술 여부
- 급여 금액
- 비급여 금액
- 본인부담금
- 약제비

### 원칙

OCR 원문은 확정 데이터가 아니다.
사용자가 확인한 값만 청구 사건에 반영한다.

---

## 7. 청구 사건 관리

### 정의

청구 사건은 하나의 병원 진료 또는 치료 묶음이다.

### 입력값

- 가족 구성원
- 진료일
- 병원명
- 진단코드
- 진단명
- 통원/입원/수술/약제비 여부
- 급여 금액
- 비급여 금액
- 약제비
- 관련 문서
- 메모

### 연결

하나의 청구 사건은 여러 보험사 청구 이력과 연결될 수 있다.

---

## 8. 보험사별 청구 관리

### 정의

ClaimSubmission은 하나의 청구 사건을 특정 보험사/담보에 청구한 기록이다.

### 입력값

- 청구 사건
- 보험
- 담보
- 청구일
- 청구금액
- 제출서류
- 처리상태
- 메모

### 처리상태

- 준비중
- 청구완료
- 추가서류요청
- 심사중
- 지급완료
- 부지급
- 취소

---

## 9. 지급 결과 관리

### 저장 항목

- 연결된 보험사별 청구 기록
- 지급일
- 지급금액
- 지급 담보
- 지급상태
- 부지급 사유
- 삭감 사유
- 추가서류 메모

### 저장 제외

- 계좌번호
- 주민번호
- 카드번호

---

## 10. 청구 참고 조회

### 입력 조건

- 가족 구성원
- 진단코드
- 진단명 선택 입력
- 진료구분
- 약제비 여부
- 수술 여부
- 진료일

### 조회 대상

- 가족 구성원의 등록 보험
- 보험별 담보/특약
- 과거 청구 사건
- 과거 지급 결과

### 결과 구분

| 구분 | 의미 |
|---|---|
| 해당 가능 담보 | 현재 입력 조건과 담보 조건이 비교적 일치 |
| 확인 필요 담보 | 일부 조건은 맞지만 추가 확인 필요 |
| 현재 조건과 불일치 | 입원/통원/수술 등 주요 조건 불일치 |
| 과거 유사 청구 | 과거 동일·유사 진단코드 청구 기록 있음 |

---

## 11. 알림성 체크

### 미청구 가능성

조건:

- 병원 서류 또는 청구 사건 있음
- 보험사별 청구 이력 없음

표시:

- 미청구 가능성 있음

### 입금 확인 필요

조건:

- 청구완료 상태
- 지급 결과 없음
- 기준일 이상 경과

표시:

- 입금 확인 필요

---

## 12. 금지 표현

앱은 다음 표현을 사용하지 않는다.

- 청구 가능 확정
- 보험금 지급 확정
- 부지급 확정
- 예상 지급금 확정
