# 유저플로우: 가족 보험 청구 참고 조회기

## 1. 전체 핵심 흐름

```mermaid
flowchart TD
    A[문서 또는 정보 등록] --> B{등록 유형 선택}
    B --> C[보험 조회 캡처/PDF]
    B --> D[약관 PDF/DOCX]
    B --> E[진단서/영수증 이미지]

    C --> C1[로컬 OCR]
    C1 --> C2[보험 후보값 추출]
    C2 --> C3[사용자 확인]
    C3 --> C4[보험 목록 저장]

    D --> D1[로컬 텍스트 추출]
    D1 --> D2[담보 후보 추출]
    D2 --> D3[사용자 확인]
    D3 --> D4[담보/특약 저장]

    E --> E1[로컬 OCR]
    E1 --> E2[청구 입력 후보 추출]
    E2 --> E3[사용자 확인]
    E3 --> E4[청구 사건 생성]

    C4 --> F[청구 참고 조회]
    D4 --> F
    E4 --> F
    F --> G[담보 규칙 조회]
    F --> H[과거 청구 이력 조회]
    G --> I[청구 참고 결과 표시]
    H --> I
```

---

## 2. 보험 목록 반자동 등록 흐름

```mermaid
flowchart TD
    A[보험 목록 화면] --> B[이미지/PDF에서 등록 클릭]
    B --> C[파일 선택]
    C --> D[로컬 OCR 또는 텍스트 추출]
    D --> E[보험사명/상품명/피보험자 후보 표시]
    E --> F{사용자 판단}
    F -->|확인| G[보험 목록으로 저장]
    F -->|수정| H[후보값 수정]
    H --> G
    F -->|무시| I[후보 폐기]
    G --> J[보험 상세 화면]
```

---

## 3. 약관 담보 후보 등록 흐름

```mermaid
flowchart TD
    A[보험 상세 화면] --> B[약관 문서 추가]
    B --> C[PDF/DOCX 선택]
    C --> D[로컬 텍스트 추출]
    D --> E[담보명/지급사유/면책 후보 추출]
    E --> F[담보 후보 목록]
    F --> G{사용자 판단}
    G -->|등록| H[담보/특약 저장]
    G -->|수정 후 등록| I[담보 규칙 수정]
    I --> H
    G -->|무시| J[후보 무시]
    H --> K[청구 참고 조회에서 사용]
```

## 4. 병원 서류 OCR 및 청구 사건 생성 흐름

```mermaid
flowchart TD
    A[문서 등록 화면] --> B[진단서/영수증 이미지 추가]
    B --> C[문서 유형 선택]
    C --> D[로컬 OCR]
    D --> E[진료일/병원명/진단코드/금액 후보 표시]
    E --> F{사용자 확인}
    F -->|확인| G[청구 사건 생성]
    F -->|수정| H[후보값 수정]
    H --> G
    F -->|보류| I[OCR 확인함에 보관]
    G --> J[보험사별 청구 등록]
```

---

## 5. 보험사별 청구 및 지급 결과 흐름

```mermaid
flowchart TD
    A[청구 사건 상세] --> B[보험사별 청구 추가]
    B --> C[보험 선택]
    C --> D[담보 선택]
    D --> E[청구일/청구금액/제출서류 입력]
    E --> F[ClaimSubmission 저장]
    F --> G{제출 처리}
    G -->|추가서류| H[추가서류 요청 저장]
    H --> G
    G -->|처리 완료| I[ClaimPayment pending 생성]
    I --> J{지급 결과}
    J -->|지급| K[지급일/지급금액/담보 저장]
    J -->|부분 지급| L[지급 정보와 삭감 사유 저장]
    J -->|부지급| M[부지급 사유 저장]
    J -->|취소| N[결과 없이 취소 저장]
    K --> O[과거 지급 사례로 사용]
    L --> O
    M --> O
```

## 6. 청구 참고 조회 흐름

```mermaid
flowchart TD
    A[청구 참고 조회 화면] --> B[가족 구성원 선택]
    B --> C[진단코드 입력]
    C --> D[통원/입원/수술/약제비 조건 입력]
    D --> E[조회 실행]
    E --> F[등록 담보 규칙 매칭]
    E --> G[과거 청구 이력 검색]
    F --> H[결과 분류]
    G --> H
    H --> I[해당 가능 담보]
    H --> J[확인 필요 담보]
    H --> K[현재 조건과 불일치]
    H --> L[과거 유사 청구]
```

---

## 7. 미청구/입금 확인 흐름

```mermaid
flowchart TD
    A[홈 대시보드] --> B[청구 사건 목록 조회]
    B --> C{청구 이력 존재?}
    C -->|없음| D[미청구 가능성 표시]
    C -->|있음| E{지급 결과 존재?}
    E -->|없음 + 일정기간 경과| F[입금 확인 필요 표시]
    E -->|있음| G[완료]
```
