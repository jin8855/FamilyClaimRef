# 화면 목록: 가족 보험 청구 참고 조회기

| 번호 | 화면명 | 목적 | MVP |
|---:|---|---|---:|
| 01 | 홈 대시보드 | 전체 현황, 미청구/입금 확인 | 포함 |

## 2. 화면별 상세

### 01. 홈 대시보드

목적:
- 가족별 보험/청구 현황을 한눈에 본다.
- 미청구 가능성, 입금 확인 필요 건을 표시한다.

주요 요소:
- 가족별 보험 수
- 최근 청구 사건
- 미청구 가능성 목록
- 입금 확인 필요 목록
- OCR 확인 대기 목록

이동:
- 보험 목록
- OCR 확인함
- 청구 사건 상세
- 청구 참고 조회

---

### 02. 가족 구성원 관리

목적:
- 가족 구성원을 등록하고 보험/청구를 연결한다.

입력:
- 표시명
- 관계
- 메모

금지:
- 주민번호 저장 금지
- 상세주소 저장 금지

---

### 03. 보험 목록

목적:
- 가족별 가입 보험을 조회한다.
- 캡처/PDF 기반 반자동 등록을 시작한다.

주요 기능:
- 직접 등록
- 이미지/PDF에서 등록
- 가족별 필터
- 보험사별 필터
- 계약상태 필터

---

### 04. 보험 상세

목적:
- 보험 기본정보, 약관, 담보/특약을 관리한다.

주요 요소:
- 보험 기본정보
- 연결 약관 문서
- 담보/특약 목록
- 과거 청구 이력
- 지급 결과 요약

---

### 05. 담보/특약 관리

목적:
- 약관에서 추출한 담보 후보를 사용자가 확인하고 규칙으로 저장한다.

주요 입력:
- 담보명
- 진료구분
- 진단코드 규칙
- 비용구분
- 약제비 포함 여부
- 출처 문서/페이지
- 메모

---

### 06. 문서 등록

목적:
- 보험 조회 캡처, 약관, 진단서, 영수증 등 원본 파일을 등록한다.

문서 유형:
- 보험 조회 캡처
- 보험증권
- 약관
- 진단서
- 진료비 영수증
- 약제비 영수증
- 진료비 세부내역서

---

### 07. OCR 결과 확인

목적:
- OCR 또는 텍스트 추출 결과를 사용자가 확인한다.

상태:
- 확인 필요
- 수정됨
- 확정 저장됨
- 보류
- 무시

중요 원칙:
- OCR 결과는 자동 확정하지 않는다.

---

### 08. 청구 사건 등록

목적:
- 하나의 병원 진료 건을 저장한다.

입력:
- 가족 구성원
- 진료일
- 병원명
- 진단코드
- 진단명
- 진료구분
- 금액
- 관련 문서

---

### 09. 보험사별 청구 이력

목적:
- 하나의 청구 사건을 여러 보험사/담보에 청구한 기록을 관리한다.

입력:
- 보험
- 담보
- 청구일
- 청구금액
- 제출서류
- 처리상태

---

### 10. 지급 결과 관리

목적:
- 실제 지급, 부지급, 삭감, 추가서류 요청 결과를 저장한다.

입력:
- 지급일
- 지급금액
- 지급상태
- 부지급 사유
- 삭감 사유
- 메모

저장 제외:
- 계좌번호

---

### 11. 청구 참고 조회

목적:
- 진단코드와 진료 조건 기준으로 해당 가능 담보를 찾는다.

입력:
- 가족 구성원
- 진단코드
- 통원/입원/수술 여부
- 약제비 여부
- 진료일

결과:
- 해당 가능 담보
- 확인 필요 담보
- 현재 조건과 불일치
- 과거 유사 청구

---

### 12. 문서함

목적:
- 등록된 모든 원본 문서와 OCR 상태를 관리한다.

기능:
- 문서 검색
- 문서 유형 필터
- OCR 상태 필터
- 연결된 보험/청구 사건 표시

---

### 13. 설정

2차 범위.

후보 기능:
- 앱 비밀번호
- DB 암호화 설정
- 백업/복원
- OCR 언어 설정
- 첨부파일 저장 위치
