# Figma / FigJam 이전 가이드

## 1. 목적

이 문서는 ChatGPT가 작성한 기획 문서를 Figma 또는 FigJam에 옮겨 시각화하기 위한 기준이다.

Figma는 개발 도구가 아니라 화면과 흐름을 검토하기 위한 시각화 도구로 사용한다.

---

## 2. Figma 사용 원칙

- 실제 개인정보 입력 금지
- 실제 보험증권 이미지 업로드 금지
- 실제 진단서/영수증 업로드 금지
- 실제 병원명 입력 금지
- 실제 가족 실명 입력 금지
- 익명 샘플 데이터만 사용
- Figma AI 사용하지 않음
- Low-Fi 와이어프레임부터 작성

---

5. 보험사별 청구 등록
6. 지급 결과 입력
7. 청구 참고 조회
8. 미청구/입금 확인 체크

## 9. Figma 검토 체크리스트

Codex 개발 전 Figma에서 다음을 확인한다.

- OCR 후보값이 확정 데이터로 바로 넘어가지 않는가?
- 보험 목록과 약관 문서가 연결되는가?
- 약관 문서와 담보/특약이 연결되는가?
- 병원 서류와 청구 사건이 연결되는가?
- 청구 사건과 보험사별 청구 이력이 분리되어 있는가?
- 보험사별 청구 이력과 지급 결과가 연결되어 있는가?
- 청구 참고 조회에서 과거 유사 청구를 볼 수 있는가?
- 미청구 가능성과 입금 확인 필요 상태가 홈에서 보이는가?
- 계좌번호, 주민번호, 카드번호 입력란이 없는가?
