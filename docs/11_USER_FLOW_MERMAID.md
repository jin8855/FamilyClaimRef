# 사용자 흐름 Mermaid

## 1. 목적

이 문서는 V5.5 기준으로 정적 Low-Fi 와이어프레임에서 검토할 사용자 흐름을 정리한다. 실제 DB, OCR, runtime 구현은 포함하지 않는다.

## 2. 보험 청구하기 5단계 흐름

```mermaid
flowchart TD
    A["홈"] --> B["보험 청구하기"]
    B --> C["청구 시작(서류/이미지 추가)"]
    C --> D["OCR 확인"]
    D --> E["보험 찾기"]
    E --> F["진행 현황"]
    F --> G["청구 완료"]
```

## 3. 청구 서류 등록 보조 흐름

```mermaid
flowchart TD
    A["청구 시작(서류/이미지 추가)"] --> B["청구 서류 등록"]
    B --> C["OCR 확인"]
    C --> D["보험 찾기"]
```

## 4. 이력 보기 상세 흐름

```mermaid
flowchart TD
    A["이력 보기"] --> B["이력 목록"]
    B --> C["보기"]
    C --> D["이력 상세"]
    D --> E["닫기"]
    E --> A
```

## 5. 등록/편집 닫기 흐름

```mermaid
flowchart TD
    A["등록/편집 화면"] --> B["닫기"]
    B --> C["부모 화면"]
    D["보험 상세"] --> E["닫기"]
    E --> F["보험 검색"]
```

## 6. 보험 찾기 우측 패널 흐름

```mermaid
flowchart TD
    A["보험 찾기"] --> B["과거 유사 청구 Top 3"]
    B --> C["+ 클릭"]
    C --> D["우측 패널 열림"]
    D --> E["최대 20건 확인"]
    E --> F["필요 시 패널 내부 페이지"]
    F --> G["닫기"]
    G --> H["현재 화면 유지"]
    D --> I["전체 이력 보기"]
    I --> J["통합 이력 목록"]
```

## 7. 분류/태그 관리 흐름

```mermaid
flowchart TD
    A["관리하기"] --> B["분류/태그 관리"]
    B --> C["분류 등록/편집"]
    B --> D["항목 등록/편집"]
    C --> B
    D --> B
```
