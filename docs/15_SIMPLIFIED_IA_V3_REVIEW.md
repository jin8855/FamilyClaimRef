# Simplified IA V3 Review

## 1. 목적

복잡해진 v2 와이어프레임을 사용자 업무 기준의 4개 대메뉴 구조로 단순화한 내용을 기록한다.

## 2. 변경 전 문제

- 홈에서 너무 많은 세부 화면이 바로 노출됨
- 사용자가 처음 해야 할 행동이 명확하지 않음
- 관리 화면과 청구 화면이 같은 레벨에 있어 복잡함
- 보험 검색과 청구 참고 조회가 혼동될 수 있음

## 3. 변경 후 대메뉴

1. 보험 청구하기
2. 보험 검색
3. 이력 보기
4. 관리하기

## 4. 메뉴별 책임

### 보험 청구하기

청구 준비, OCR 확인, 청구 참고 조회, 청구 진행 현황, 청구 이력을 포함한다.

### 보험 검색

보유 보험과 담보 내용을 확인하는 기능이다. 청구 이력은 중심 기능이 아니다.

### 이력 보기

과거 청구 사건, 보험사별 청구 이력, 지급 결과, 유사 청구를 조회한다.

### 관리하기

가족, 보험, 문서를 관리한다.

## 5. 아직 검토할 항목

- 보험 청구하기 안에서 OCR 확인 순서가 자연스러운가
- 보험 검색과 청구 참고 조회가 충분히 분리되는가
- 이력 보기가 청구 진행 현황과 겹치지 않는가
- 관리하기에 보험 관리와 보험 검색이 중복되어 보이지 않는가
- 홈의 4개 메뉴만으로 사용자가 길을 잃지 않는가
