# Wireframe V4 Workflow Review

## 1. 목적

v3에서 단순화한 4개 대메뉴 구조를 유지하면서, 실제 사용에 필요한 저장, 임시저장, 조건 검색, 이력 더보기, 가족 등록, 보험 등록 흐름을 보강한 내용을 기록한다.

## 2. v4 주요 개선

- 청구 시작 입력에 가족 선택, 저장, 임시저장, 임시저장 불러오기, 조건 검색 추가
- 청구 흐름 단계바를 관련 화면에 공통 적용
- 청구 진행 현황에서 과거 이력은 상위 3건 + 더보기로 분리
- 이력 보기 전용 화면 추가
- 보험 검색과 보험 관리 분리
- 보험 등록 화면 추가
- 가족 등록 화면 추가
- OCR 확인함을 문서 확인 공통 화면으로 재정의

## 3. 아직 검토할 항목

- 임시저장과 저장의 차이가 화면에서 충분히 보이는가
- 조건 검색 버튼의 위치가 자연스러운가
- 청구 흐름 단계바가 너무 많은 화면 공간을 차지하지 않는가
- 이력 보기 화면이 실제 이력 조회에 충분한가
- 보험 관리와 보험 검색의 역할이 헷갈리지 않는가
- 보험 등록 화면에서 약관과 보험 요약을 함께 넣는 구조가 적절한가
- 가족 등록 화면에서 민감정보 저장 제외 기준이 충분한가
