# Wireframe V5 Review

## 1. 목적

V5 산출물은 4개 대메뉴, 청구 시작, 보험 검색, 이력 보기, 관리하기 구조를 안정화하기 위한 정적 Low-Fi 기준선이다. 이 문서는 V5부터 V5.5까지 반영된 주요 변경 사항을 기록한다.

## 2. V5 주요 변경

- 보험 청구하기를 청구 시작(서류/이미지 추가)에서 시작하도록 정리
- 과거 유사 청구를 Top 3 + 더보기 구조로 변경
- 진행 현황의 각 이력 영역에 더보기 추가
- 이력 보기 구조를 통합 이력 목록으로 정리
- 보험 검색에 진단명, 진료상황, 기간, 키워드/태그 조건 추가
- 관리하기에 보험 관리와 분류/태그 관리 진입 추가

## 3. V5.4 보완

- 우측 패널의 더보기 목록을 최대 20건 구조로 보강
- 우측 패널 내부에 페이지 영역 추가
- 전체 이력 보기를 패널 상단의 닫기 왼쪽으로 이동
- 가족 등록/편집 액션 영역을 상단으로 이동
- 분류 등록/편집 화면 추가
- 항목 등록/편집 화면 추가
- 청구 흐름 단계바를 5단계로 재고정
- 청구 서류 등록은 독립 단계가 아니라 청구 시작 단계 안의 보조 화면으로 유지

## 4. V5.5 Action Alignment and Detail View 보완

- 다음 작업 영역을 타이틀 왼쪽, 버튼 오른쪽 구조로 정렬
- 패널 타이틀 영역 여백 축소
- 보험 상세 화면에 닫기 버튼 추가
- 보험 검색과 이력 보기의 검색 조건 영역 오른쪽에 홈 버튼 추가
- 이력 상세 화면 추가
- 등록/편집/상세 화면 상단 오른쪽에 닫기 버튼 추가
- 보험 등록/편집 화면의 액션 타이틀 제거
- 관리하기 전체 화면 목록을 기본 접힘 상태로 변경

## 5. 아직 검토할 항목

- 오른쪽 정렬 버튼이 모바일에서 지나치게 줄바꿈되지 않는가
- 닫기 버튼 위치가 모든 등록/편집 화면에서 일관되는가
- `details/summary` 접힘 UI가 충분히 눈에 띄는가
- 이력 상세 화면의 정보량이 과하지 않은가
