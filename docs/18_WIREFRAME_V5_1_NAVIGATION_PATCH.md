# Wireframe V5.1 Navigation Patch

## 1. 목적

V5 화면을 브라우저로 검토한 뒤 발견된 네비게이션, 단계바, 문서 등록/조회 분리, 관리 버튼 크기 문제를 보정한다.

## 2. 주요 변경

- 모든 화면 상단에 breadcrumb 네비게이션 추가
- 홈 링크 복구
- 청구 흐름을 5단계로 정리
- 청구 시작 단계에 서류/이미지 추가를 포함
- 전체 화면 목록을 관리하기 하단으로 이동
- 더보기/편집/삭제/사용 중지 버튼 소형화
- 보험 등록 액션을 상단으로 이동
- 분류/태그 관리에 등록/편집/삭제 추가
- 보험 관리에서 직접 OCR 버튼 제거
- 보험 문서 등록과 청구 서류 등록 화면 분리
- 문서함을 등록이 아닌 조회/관리 화면으로 재정의

## 3. 아직 검토할 항목

- breadcrumb가 모든 화면에서 충분히 눈에 띄는가
- 5단계 청구 흐름이 더 자연스러운가
- 보험 문서 등록과 청구 서류 등록의 구분이 명확한가
- OCR 공통 화면으로 이동할 때 진입 출처가 충분히 표시되는가
- 관리 화면의 작은 액션 버튼이 너무 작지 않은가
- Top 3 더보기는 화면 전환이 아니라 레이어/팝업으로 처리되어야 한다.

## 4. V5.2 후속 보완 필요

- header를 한 줄 topbar 구조로 줄인다.
- breadcrumb는 오른쪽에 배치하고 홈 링크를 유지한다.
- 보험 문서 등록은 선택된 보험에 종속된 화면으로 재정의한다.
- 약관/계약서/보험증권은 보험 등록/편집 후 연결한다.
- 문서 이미지 연결과 사용자의 문서 내용 확인을 분리한다.
- 분류/태그 관리에 좌측 분류 리스트와 우측 항목 목록을 복구한다.
