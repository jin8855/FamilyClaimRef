# Wireframe V5.2 Policy Document Flow Patch

## 1. 목적

V5.1 브라우저 검토 후 발견된 header 가독성 문제와 보험 문서 등록 흐름 오류를 보정한다.

## 2. 주요 변경

- header를 왼쪽 제목, 오른쪽 breadcrumb 구조로 축소
- 보험 문서 등록을 선택된 보험에 종속된 화면으로 재정의
- 보험 등록/편집 화면에서 약관/계약서/보험증권 연결을 명확히 함
- 보험 문서 등록 화면에 선택된 보험 요약 영역 추가
- 문서 이미지 연결과 사용자 내용 확인을 분리
- OCR 확인 화면에 문서 목적, 연결 대상, 진입 출처 표시
- 분류/태그 관리에 좌측 분류 리스트와 우측 항목 목록 복구

## 3. 검토 기준

- 보험을 등록하지 않고 약관/계약서를 넣는 흐름처럼 보이지 않는가
- 약관/계약서/보험증권이 특정 보험에 연결되어 보이는가
- 청구 서류와 보험 문서가 명확히 분리되는가
- header가 과하게 높지 않고 breadcrumb가 잘 보이는가
- 분류/태그 관리에서 분류와 항목의 관계가 보이는가
