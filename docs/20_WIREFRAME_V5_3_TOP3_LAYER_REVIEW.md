# Wireframe V5.3 Top3 Layer Review

## 1. 목적

청구 진행 중 Top 3 더보기 액션이 화면 전환을 일으키지 않도록 우측 패널 방식으로 보이게 수정한 내용을 기록한다.

## 2. 배경

기존 더보기는 이력 보기 화면으로 이동하는 구조였다. 보험 청구 진행 중 화면이 전환되면 현재 청구 맥락이 끊길 수 있으므로, 현재 화면을 유지한 채 추가 후보를 확인하는 구조가 필요했다.

## 3. 변경 사항

- 보험 찾기 화면의 과거 유사 청구 Top 3 더보기를 우측 패널로 변경
- 진행 현황 화면의 보험사별 청구 이력 최근 3건 더보기를 우측 패널로 변경
- 진행 현황 화면의 지급 결과 최근 3건 더보기를 우측 패널로 변경
- 진행 현황 화면의 과거 유사 청구 최근 3건 더보기를 우측 패널로 변경
- 전체 이력 보기는 보조 링크로 유지

## 4. 설계 기준

- 현재 청구 진행 화면에서 이탈하지 않는다.
- 더보기는 상세 확인용이다.
- 전체 이력 검색이 필요할 때만 이력 보기로 이동한다.
- 정적 HTML에서는 실제 팝업 동작을 구현하지 않고 CSS `:target` 기반 우측 패널로 표시한다.

## 5. 아직 검토할 항목

- 우측 패널 내용이 화면을 너무 복잡하게 만들지 않는가
- 실제 앱 구현 시 팝업, 우측 패널, 하단 슬라이드 중 어떤 방식이 적합한가
- 모바일 크기에서 별도 전체 화면 패널이 더 적합한가

## 6. 후속 패치

- 하단에 항상 노출되던 상세 박스 영역을 제거했다.
- 더보기 상세 표현을 `+`로 통일했다.
- `+` 클릭 후 CSS `:target` 기반 우측 패널이 열리는 정적 HTML 구조로 변경했다.
- 전체 이력 보기는 우측 패널 내부의 보조 링크로 유지했다.

## 7. V5.4 후속 보완

- 우측 패널이 3건만 보여주는 문제를 보완해 최대 20건 목록 구조로 변경한다.
- 우측 패널 하단에 페이지 영역을 추가한다.
- 전체 이력 보기를 패널 상단 액션 영역으로 이동한다.
- 화면 전환 없이 현재 화면을 유지한다는 V5.3 기준은 유지한다.
