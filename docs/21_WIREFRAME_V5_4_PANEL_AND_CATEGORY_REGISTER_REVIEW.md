# Wireframe V5.4 Panel and Category Register Review

## 1. 목적

V5.3에서 우측 패널 구조는 잡혔지만 더보기 목록 수, 전체 이력 보기 위치, 분류/항목 등록 화면 누락 문제가 남아 있었다. 이 문서는 V5.4 보완 내용과 V5.5 후속 보완 필요 항목을 기록한다.

## 2. V5.4 주요 변경

- 우측 패널 목록을 최대 20건 구조로 보강
- 우측 패널 내부 페이지 영역 추가
- 전체 이력 보기를 닫기 왼쪽 상단 액션으로 이동
- 가족 등록/편집 액션 영역을 상단으로 이동
- 분류 등록/편집 화면 추가
- 항목 등록/편집 화면 추가
- 분류/태그 관리의 등록/편집 버튼 연결
- 청구 흐름 단계바는 5단계 기준을 유지하고 청구 서류 등록은 보조 화면으로 둠

## 3. 설계 기준

- Top 3는 본문 요약이다.
- 우측 패널은 추가 후보 최대 20건을 확인하는 영역이다.
- 20건 초과는 패널 내부 페이지 구조로 처리한다.
- 전체 이력 보기는 패널 상단 보조 액션이다.
- 분류와 항목은 별도 등록/편집 화면을 가진다.
- 보험 청구하기 단계바는 청구 시작(서류/이미지 추가), OCR 확인, 보험 찾기, 진행 현황, 청구 완료의 5단계이다.
- 청구 서류 등록은 `18_claim_document_register.html` 보조 화면이며 독립 단계로 표시하지 않는다.

## 4. 아직 검토할 항목

- 우측 패널의 20건 구조가 너무 길어 보이지 않는가
- 실제 앱에서는 무한 스크롤보다 페이지가 적합한가
- 분류와 항목 등록 화면이 과도하게 복잡하지 않은가
- 가족 등록/편집 상단 액션이 다른 관리 화면과 일관되는가

## 5. V5.5 후속 보완 필요

- 다음 작업 버튼은 오른쪽 정렬한다.
- 등록/편집/상세 화면에는 닫기 버튼을 둔다.
- 검색 조건 영역 오른쪽에는 홈 버튼을 둘 수 있다.
- 관리하기 전체 화면 목록은 기본 접힘 상태가 적합하다.
