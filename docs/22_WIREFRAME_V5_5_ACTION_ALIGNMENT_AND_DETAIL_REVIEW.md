# Wireframe V5.5 Action Alignment and Detail Review

## 1. 목적

V5.4 이후 브라우저 검토에서 발견된 버튼 정렬, 닫기 버튼, 이력 상세 화면 누락, 전체 화면 목록 펼침 문제를 보완한다.

## 2. 주요 변경

- 다음 작업 영역을 왼쪽 타이틀, 오른쪽 버튼 구조로 통일
- 패널 타이틀 영역 여백 축소
- 보험 상세 화면에 닫기 버튼 추가
- 보험 검색 검색 조건 오른쪽에 홈 버튼 추가
- 이력 보기 검색 조건 오른쪽에 홈 버튼 추가
- 이력 상세 화면 추가
- 등록/편집/상세 화면에 닫기 버튼 추가
- 보험 등록/편집 화면의 액션 타이틀 제거
- 관리하기 전체 화면 목록을 `details` / `summary` 기반 기본 접힘 구조로 변경

## 3. 설계 기준

- 다음 작업은 진행 방향이므로 오른쪽에 배치한다.
- 등록/편집/상세 화면은 닫기 버튼으로 부모 화면에 돌아간다.
- 검색 조건 화면에서는 홈 복귀가 빠르게 가능해야 한다.
- 전체 화면 목록은 관리용 보조 정보이므로 기본 접힘 상태가 맞다.
- JavaScript 없이 HTML 기본 기능만 사용한다.

## 4. 아직 검토할 항목

- 오른쪽 정렬 버튼이 모바일에서 지나치게 줄바꿈되지 않는가
- 닫기 버튼 위치가 모든 등록/편집 화면에서 일관되는가
- details/summary 접힘 UI가 충분히 눈에 띄는가
- 이력 상세 화면의 정보량이 과하지 않은가

## 5. V5.5 후속 보정

- 문서함의 등록/이동 액션을 오른쪽 보조 버튼으로 정렬한다.
- 문서함은 조회/관리 화면으로 보이도록 문서 목록과 문서 유형 조회를 중심에 둔다.
- 보험 관리 상단 액션을 오른쪽 정렬한다.
- 보험 문서 등록은 상단 주요 버튼이 아니라 보험 행의 문서 추가에서 진입하는 흐름을 유지한다.
